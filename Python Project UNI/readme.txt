
ПРОЕКТ: АВТОСАЛОН Uloff Auto Showroom


ОПИСАНИЕ:
Проектът представлява конзолно приложение на Python за управление на автосалон.
Разделен е на модулна структура (два основни файла) според изискванията.

СТРУКТУРА НА ФАЙЛОВЕТЕ:
1. models.py - Съдържа бизнес логиката и дефинициите на класовете `Car` и `CarShowroom`.
2. main.py - Главен изпълним файл, който тества логиката, филтрира и сортира данните.
3. requirements.txt - Списък с използваните външни библиотеки.
4. readme.txt - Настоящото упътване.

ИЗПОЛЗВАНИ БИБЛИОТЕКИ:
- `tabulate`: Използва се за генериране на чисти, подредени и четими таблици в терминала.

КАК СЕ СТАРТИРА:
1. Отворете терминала в папката на проекта.
2. Инсталирайте нужните пакети чрез командата:
   pip install -r requirements.txt
3. Стартирайте проекта:
   python main.py
4. Задължително да се използва PowerShell
